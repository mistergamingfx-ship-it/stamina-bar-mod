STAMINA BAR — Minecraft 1.12.1 (Forge)

СОДЕРЖИМОЕ
- Полоска выносливости на HUD.
- Выносливость расходуется при спринте и прыжке.
- Восстанавливается, когда игрок не бежит.
- При нуле выносливости спринт отключается.
- Цвет полоски: зелёный / жёлтый / красный.

СБОРКА
1. Установи Java 8 (JDK).
2. Установи Forge MDK для Minecraft 1.12.1.
3. Открой папку проекта в терминале.
4. Выполни: gradlew setupDecompWorkspace
5. Затем: gradlew build
6. Готовый JAR появится в build/libs/.
7. Скопируй JAR в .minecraft/mods и запусти профиль Forge 1.12.1.

ВАЖНО
Это первая клиентская версия: механика и HUD работают на стороне клиента.
В мультиплеере сервер не проверяет расход выносливости, поэтому для полноценной
защиты от обхода механики потребуется отдельная серверная синхронизация.
Настройки создаются в config/StaminaBar.cfg.


АВТОСБОРКА ЧЕРЕЗ GITHUB ACTIONS
1. Загрузи всё содержимое проекта в GitHub-репозиторий.
2. Проверь, что файл .github/workflows/build.yml находится именно по этому пути.
3. Открой вкладку Actions в репозитории.
4. Запусти workflow Build Stamina Bar (или сделай push в main/master).
5. После успешной сборки открой запуск workflow и скачай artifact
   StaminaBar-Minecraft-1.12.1. Внутри будет готовый JAR.
